# Kittie Has Other Plans

A native Game Boy Color game for ModRetro Chromatic, built with GB Studio.
Kittie's journey spans a courtyard, an olive grove, and a wedding banquet.

Open [`courtyard/project.gbsproj`](courtyard/project.gbsproj) in GB Studio 4.3.2.
The project includes custom engine code, game assets, Python art and level tools,
and HTML design and review guides.

- [Play guide](design/version-1.html)
- [Project and development notes](courtyard/README.md)
- [Whole-level development workflow](design/agent-workflow.html)

Generated builds, playtest recordings, and emulator save states are excluded
from this repository. The project notes refer to local verification artifacts
that are not included here.
