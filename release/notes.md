Kittie Has Other Plans is a native Game Boy Color game for ModRetro Chromatic.

- Three connected stages and 28 screens: courtyard, olive grove, and wedding banquet.
- Three physical wool balls per stage, constant-speed goons, full-stage retries, and saved stage unlocks.
- Approved Kittie art, portrait cover, stage music, environment textures, and wedding ending.

This release preserves the exact final reviewed cartridge. It passed a complete three-stage emulator run and recovered all stage unlocks after a native soft restart. The owner reported a successful Chromatic playtest.

Download the .gbc file and SHA256SUMS below. Controls: D-pad moves, A jumps, B throws, Up+B lobs, Start retries, and Select returns to the cover.

See design/version-1.html in the source for the play guide and maps, and release/manifest.json for the cartridge identity.
