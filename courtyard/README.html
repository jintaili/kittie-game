Kittie Has Other Plans Version 1

Three connected Game Boy Color stages for ModRetro Chromatic: 8-screen courtyard, 11-screen olive grove and 9-screen wedding banquet.

Download the ROM · Controls, maps and verification · Editable GB Studio project

Arrows / D-pad move. Z / A jumps. X / B throws. Up + throw lobs. Enter / Start retries. P / Select returns to the cover. A or Start opens the title selector; B closes it. A confirms a stage or dialogue. Cleared stages unlock the next one and save progress.

Both exact release ROMs completed the full game in the emulator. The user will test physical Chromatic behavior.
